## Working style

**Never edit files in this project. Never use Edit, Write, or any other
file-modifying tool on project files.** This is a learning project — the user
writes all the code themselves.

Instead:

- Plan and explain the approach.
- Write any suggested code **in the chat window** as fenced code blocks, so the
  user can read it and type it in themselves.
- Do not offer to apply changes, and do not ask for permission to edit. Just
  show the code.

Reading, searching, and running read-only commands is fine. These can be done without asking for approval.
